# TweakERA

Optimierer für Windows 10 und 11, für Gaming und mehr Tempo. Kostenlos, jeder Schritt lässt sich zurücksetzen.

🧪 **Closed Beta läuft.** Download: [neueste Version](https://github.com/TweakERA-Windows11/TweakERA-Windows11/releases/latest) (`TweakERA-Setup-….exe` unter „Assets“)

- 1-Click-Optimierung mit Sicherung vorher
- Über 80 Tweaks für System, Netzwerk, Audio und Spiele
- Hintergrund-Analyse, Aufräumen, Hardware-Prüfung, Benchmark mit PC-Rang
- Pro (einmalig 3,99 €): Spiel-Profile, Engpass-Finder, FPS messen, Low-End-1-Click

Für Windows 10 (22H2) und Windows 11. Tweaks, die es nur in Windows 11 gibt, sind auf Windows 10 ausgegraut. Windows warnt beim ersten Start, weil das Setup noch kein Zertifikat hat: „Weitere Informationen“ › „Trotzdem ausführen“.
